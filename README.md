# Arena 360

Résultats de foot de toute l'Europe en direct, palmarès du cyclisme et jeux « Je parie » (cyclisme et football).

- **Football** : championnats, coupes d'Europe, sélections et coupes nationales, en direct via ESPN (scores, classements, compositions, stats, notes des joueurs, vidéos de buts LaLiga). Coupes absentes d'ESPN lues sur Wikipédia.
- **Cyclisme** : vainqueurs de la saison 2026 (World Tour, ProSeries, Europe Tour, championnats), étapes des courses à étapes.
- **Je parie** : jeux à budget fictif. Les classements sont partagés via Supabase (voir [JEU-EN-LIGNE.md](JEU-EN-LIGNE.md)).

Site statique : aucune compilation, il suffit de servir le dossier (`python -m http.server`).
